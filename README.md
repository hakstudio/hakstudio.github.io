# hakstudio.github.io

Personal website and portfolio of Halil Adil Kaya — Software Developer based in Germany.

## 🌐 Live

[https://hakstudio.github.io](https://hakstudio.github.io)

## Features

- **Dark theme** with smooth animations
- **Responsive** — mobile, tablet, desktop
- **Multi-language** — English (default), German, Turkish
- **Portfolio page** with project filtering (Mobile / Web / Full-Stack / Game)
- **Zero dependencies** — pure HTML, CSS, vanilla JS

## Structure

```
├── index.html          # Main page (Hero, About, Projects, Timeline, Contact)
├── portfolio.html      # Full portfolio with all projects
├── css/style.css       # Design system
├── js/main.js          # Animations, scroll effects, mobile menu, filters
├── js/i18n.js          # Language switching
├── i18n/               # Translation files (en, de, tr)
└── assets/images/      # Logo, favicon, project images
```

## Development

Open `index.html` in a browser. No build step required.

For local development with live reload:
```bash
npx serve .
```
